Data & methods

  • Grid data: IESO public reports (zonal demand, generation by fuel, realtime Ontario zonal price). Weather: Open-Meteo archive API.
  • Each headline card shows its own timestamp because the feeds update on different schedules (grid data lags ~1 day, Open-Meteo weather ~5 days, the realtime price is minutes old).
  • Renewable share = (biofuel + hydro + solar + wind) / total reported generation for the latest hour. Non-emitting share adds nuclear to the numerator.
  • Ontario zonal price = hourly average of the realtime 5-minute Ontario zonal energy price (the hourly average is also the value IESO uses for settlement). Each hourly run appends the latest hour to data/processed/price_hourly.csv, so the repo keeps a growing price history.
  • All timestamps are America/Toronto local time.
